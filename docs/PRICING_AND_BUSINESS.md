## 7. B2B 비즈니스 모델: 하이브리드 전략

### 7-1. 두 가지 모델

| | Option 1: 크레딧 번들 | Option 2: BYOK (Bring Your Own Key) |
|---|---|---|
| **대상** | B2C / 소규모 B2B | B2B 기업 |
| **수익 모델** | 구독료 + 크레딧 판매 | 순수 SaaS 사용료 |
| **API 비용** | REMO가 부담 (마진 포함) | 고객이 직접 지불 |
| **마진** | 변동 (이미지↑ 영상↓) | **80%+ 고정** |
| **고객 경험** | 심플, 원스톱 | GCP/Kling 세팅 필요 |
| **스케일** | 대량 사용 시 마진 압박 | 대량 사용해도 무관 |
| **리스크** | API 가격 변동 리스크 | 리스크 제로 |

### 7-2. 적용 전략

```
B2C / 소규모 → Option 1 (크레딧 번들)
  - Free(20cr) → Starter(₩19,900) → Pro(₩49,900)
  - 크레딧 단가 재조정 필수 (매트릭스 3cr→10cr 등)

B2B 기업 → Option 2 (BYOK)
  - 고객이 GCP Gemini API + Kling API 키 직접 연결
  - REMO는 툴 사용료(SaaS fee)만 청구
  - API 호출 비용은 고객 GCP/Kling 계정에 직접 청구
```

### 7-3. BYOK B2B 가격 구조

| 티어 | 월 사용료 | 연간 | 시트 | 포함 |
|------|----------|------|------|------|
| Team | ₩300,000 | ₩3,000,000 | 5명 | 워크플로우 풀 기능 |
| Business | ₩800,000 | ₩8,000,000 | 20명 | 우선 지원, 커스텀 템플릿 |
| Enterprise | 별도 협의 | 별도 협의 | 무제한 | 전담 매니저, SLA, SSO |

> 고객은 Settings에서 API Key 입력 → REMO가 프록시 호출 → 비용은 고객 계정 청구
> REMO 마진 = 100% SaaS 수익 (API 원가 제로)
