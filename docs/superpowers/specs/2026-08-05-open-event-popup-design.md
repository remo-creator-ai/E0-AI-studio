# 소담 AI 스튜디오 오픈 이벤트 팝업 설계

## 목적

홈페이지 방문자와 로그인 사용자에게 오픈 기념 지원 프로그램을 안내하고, 제공된 Google Form으로 연결한다.

## 동작

- 홈페이지 진입 시 한국 시간 기준 2026-08-10 23:59:59까지 팝업을 노출한다.
- 홍보 이미지 전체를 클릭 가능한 링크로 사용하며 새 탭에서 신청 폼을 연다.
- 일반 닫기는 현재 화면에서만 닫는다.
- `오늘 하루 보지 않기`는 한국 날짜를 로컬 스토리지에 저장해 그날 동안 숨긴다.
- 배경 클릭과 Escape 키로도 닫을 수 있다.

## 화면

- 제공된 984×1313 세로 이미지를 비율 왜곡 없이 표시한다.
- 데스크톱과 모바일 모두 뷰포트 안에 들어오도록 최대 너비와 높이를 제한한다.
- 로그인 모달보다 앞에 보이는 어두운 배경과 명확한 닫기 버튼을 사용한다.

## 범위

- `App`의 인증 분기 위에 한 번만 표시해 로그인 전 홈페이지와 로그인 후 메인 화면에서 동일하게 동작한다.
- 서버 저장이나 새 의존성은 추가하지 않는다.

## 검증

- 활성 기간 노출, 정확한 링크, 일반 닫기, 오늘 하루 숨김, 종료일 이후 미노출을 브라우저 테스트로 검증한다.
- 실제 팝업 화면을 캡처해 제공 이미지의 가독성과 반응형 배치를 확인한다.
