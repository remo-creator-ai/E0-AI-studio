A. 이미지 생성 모델 선택 신설
1

생성 모델 드롭다운신규

components/ImageStudio.tsx · services/imageStudioService.ts

스타일과 이미지 형태 사이에 생성 모델 드롭다운이 들어갔다. 기본값은 가장 저렴한 Nano Banana 2.

동작

  • 기본값은 목록 순서가 아니라 단가로 계산해 고른다 — 모델을 추가해도 기본값이 자동으로 최저가를 따라간다.
  • 선택한 모델은 단일 생성·멀티샷(개별 6장/1시트) 전 경로에 함께 적용된다.
  • GPT Image 2 선택 시 Google SDK 가 아니라 ai-proxy 의 /openai 라우트로 우회한다.

모델별 단가

왜 단가를 나눴나 — 기존에는 모델과 무관하게 1cr 고정이었다. 여기에 모델 선택만 붙이면 원가가 비싼 모델을 고를수록 적자가 되므로, 장당 원가에 맞춰 차등했다.

B. 동영상 생성 해상도 · 크레딧 개편
3

길이 · 해상도 · 끝 프레임단가 개편

components/VideoStudio.tsx · services/videoStudioService.ts

기본 720p · 5초

1080p(PRO) 선택 → 60cr · "Pro 모드 · 크레딧 2배" 안내

크레딧 매트릭스 — 규칙: 30 × 유닛수

길이 \ 해상도720p (std)1080p · 끝 프레임 (pro)
5초30cr (1유닛)60cr (2유닛)
10초60cr (2유닛)120cr (4유닛)

왜 이렇게 바꿨나

  • 차익거래 제거 — 같은 kling-v2-6 5초인데 사이드바는 10cr, 프로젝트 씬은 30cr 이었다. 자산 보관함을 거치면 1/3 가격에 같은 결과를 얻을 수 있었다.
  • 길이 비례 회복 — 10초는 원가가 2배인데 가격은 1.5배였다. 유닛 소모량에 정비례시켜 전 조합의 마진을 균일하게 맞췄다.

끝 프레임 → 해상도 자동 전환

끝 프레임 지정→std 는 image_tail 미지원→pro 자동 승격→1080p · 크레딧 2배
화면만 봐서는 왜 해상도가 저절로 바뀌는지 알 수 없는 동작이라, 온보딩 가이드 문구로 설명을 붙였다.

D. 관리자 콘솔 키 관리
5

API 키 탭항목 추가

components/AdminPage.tsx · supabase/functions/ai-proxy

Gemini 아래에 OpenAI (GPT Image 2) 입력란이 추가됐다. 아래로 Google TTS · Kling 키가 이어진다.

키 조달 순서

admin_config (DB)→Function Secret→미설정 시 503
  • 키는 브라우저로 내려오지 않는다. Edge Function 이 서버에서 주입해 공급자로 포워드한다.
  • 관리자 콘솔에 입력하면 재배포 없이 즉시 반영된다.
구현 시 주의 — /openai 라우트는 Gemini 분기보다 먼저 평가해야 한다. Gemini 쪽이 /v1 접두사를 통째로 받으므로 순서가 뒤바뀌면 OpenAI 요청이 Google 로 나간다. 또 참조 이미지를 쓰는 /v1/images/edits 는 multipart 라서 본문을 텍스트로 읽으면 바이너리가 깨진다.
