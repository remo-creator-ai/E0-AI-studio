4. 실행 순서와 결정 항목

  1. A 또는 B 방향을 선택한다. 이름은 E0 AI Studio를 임시 유지한다.
  2. 선택한 안으로 로컬 브랜드 구성·랜딩·공통 레이아웃·대시보드를 구현한다.
  3. 작업 화면·출력물·온보딩의 문구와 테마를 일괄 정리하고 목 데이터로 검토한다.
  4. 새 Supabase·Vercel과 운영정책을 확정한 뒤 실제 인증·저장·생성·배포를 검증한다.

사용자 가설은 내부 담당자/고객사 제작자이며 아직 인터뷰하지 않았다. 승인 워크플로, 조직별 공동 자산, 장치 제어, CMS 송출은 기존 구현 사실로 간주하지 않는다.

근거와 확인 범위

  • S1 공식 홈페이지: 사업 분야와 메인 정보구조. 2026-10-12 확인.
  • S2 회사 소개: 하드웨어·소프트웨어·콘텐츠를 함께 제공하는 사업 특성.
  • S3 CMS 소개: 회사의 콘텐츠 운영 사업 맥락. E0 앱과의 연동 증거는 아님.
  • S4 공식 layout.css, basic.css: 청록색 #009481, 흑백·회색, Noto Sans KR 및 Segoe UI 선언 확인.
  • S5 공식 로고: 청록색 e와 어두운 나머지 글자를 직접 확인. 원본 비율 유지.
  • S6 LED 메인 이미지, 스마트미러 이미지: 건축 공간·화면 발광·설치 맥락을 직접 확인. 메인 연출 이미지의 실제 시공 여부는 별도 검증하지 않음.
  • 로컬 근거: styles.css, App.tsx, components/Layout.tsx, Dashboard.tsx, LandingPage.tsx, types.ts, i18n/ko.json, lib/mockAuth.ts, 기존 대시보드 스크린샷.

공식 페이지 텍스트·HTML·CSS·로고·대표 이미지를 교차 확인했다. 연결 가능한 브라우저가 없어 전체 페이지의 실제 렌더링과 모바일 동작은 검증하지 못했다. 아래 시각 해석은 소스와 이미지 관찰에 기반하며, 완성된 사이트 화면의 실측 결과가 아니다. 홈페이지 게시 수치·수상·고객사를 E0의 사용 실적이나 성능으로 전용하지 않는다.
