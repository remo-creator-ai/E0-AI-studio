1. Overview · 적용 범위

로그인 전 랜딩, 대시보드, 프로젝트 시작, 제작 4단계, 개별 생성 도구, 자산·설정·관리 화면과 내보내기 결과에 적용한다. 기능 PRD의 요구사항을 화면과 상태로 구체화한 선택 후보이며, 두 테마를 동시에 서비스하는 요구사항은 아니다.

2. Brand Concept

핵심 키워드: 신뢰·명료함·브랜드 일관성. 밝은 작업지 위에 청록색으로 다음 행동을 안내한다. 기업 워드마크와 제품 결과물이 중심이다.

회사 로고는 원본 비율을 보존하고 E0 서비스명과 분리한다. 공식 E0 로고가 없어 시안의 “E0”는 임시 텍스트 워드마크다. 공식 eone 로고를 재제작하거나 임의로 E0로 변형하지 않는다. 어두운 배경에서 원본 로고가 묻히면 밝은 보호 패널을 사용한다.

3. Design Principles

  1. 제작 결과물이 장식보다 먼저 보인다.
  2. 한 화면의 주 행동은 한 개를 우선 강조한다.
  3. 작업 단계·저장 상태·생성 상태를 구분한다.
  4. 브랜드색과 오류·경고색의 역할을 분리한다.
  5. 완료·시안·미연동 상태를 문구로 명시한다.

6. Layout & Spacing

8px 중심 간격 체계(4/8/12/16/24/32/48/64), 페이지 패딩 32px·모바일 16px, 헤더 64px, 사이드바 256px. 대시보드 본문 최대 1440px. 프로젝트 카드 3열 → 2열 → 1열, 최소 260px. 랜딩은 최대 1200px.

1280px 이상: 좌측 내비 + 넓은 프로젝트 목록. 768–1279px: 프로젝트 2열. 767px 이하: 서랍형 내비와 단일 열, 작업 단계는 현재 단계와 이전/다음 버튼으로 노출. 360px 화면에서 본문 가로 스크롤 없음. 스토리보드 캔버스만 명시적으로 확대·이동 허용.

8. Icon & Image

기존 Lucide 아이콘을 20/24px, 일관된 stroke로 유지한다. 소담이 이미지를 기본 안내자로 사용하지 않는다. 제품·설치 공간 이미지는 출처와 사용 권한을 확보한 자산으로 구성한다. 분석용 공식 이미지는 본 문서에서 참조만 하며 앱 자산으로 자동 편입하지 않는다.

랜딩은 밝은 배경에 제품 결과물 2~3개를 묶어 보여준다. 작업 화면의 배경 사진은 사용하지 않는다. 프레임 안 문구는 생성 이미지에 의존하지 않고 UI 텍스트로 구분한다. 자동 재생 영상은 기본 무음이며 일시정지를 제공한다.

9. Data Visualization

서버에서 확인된 장면 완료 수/전체 수를 진행률로 표현한다. 생성·저장·다운로드 상태를 별도 라벨로 표시한다. 크레딧 수량은 실제 값 또는 “데모 값” 표시를 사용한다. 회사의 설치·고객 수를 E0 성과 카드로 사용하지 않는다.

10. Accessibility

  • 일반 텍스트 대비 4.5:1, 큰 글자와 주요 UI 경계 3:1을 검수 목표로 한다. border는 장식용이며 컨트롤 식별은 inputBorder를 사용한다.
  • 44×44px 이상 터치 영역, 키보드 포커스 유지, 모든 아이콘 버튼에 accessible name.
  • 확대 200%에서 주요 동작 유지. 색만으로 상태 전달하지 않음.
  • prefers-reduced-motion에서 입장·전환 모션 해제. 기본 전환 150ms, 반복 발광 효과 없음.
  • 영상 음성 정보는 텍스트 대본으로도 접근 가능하게 제공. 모달·알림의 스크린리더 상태 안내.

목적·화면 방향에 맞춘 시작 카드실제로 연결되지 않은 장치·송출 버튼
정확한 현재 단계와 상태 표기소담 행사 혜택·기존 후원 문구 잔존
한정된 청록색과 명확한 경고색성공·실패·경고를 모두 브랜드색으로 처리
현실적인 결과 프레임비율 프리뷰를 실제 설치·색 정확도 보증으로 표현
