제품 정의: 브랜드 콘텐츠를 손쉽게 기획하고 이미지·영상으로 완성하는 기업형 AI 제작 공간. 사용자 가설을 기반으로 한 제안이며, 현재 앱에 특화 기능이 이미 구현되었다는 뜻은 아니다.

1. 문제·목표·범위

소담 브랜드·행사·일반 쇼츠 문구가 남아 있어 이원오엠에스의 서비스로 인식하기 어렵다. 핵심 목표는 E0의 소유감과 제작 목적을 명확하게 하고, 기존 생성 흐름을 유지하는 것이다.

이번 산출 범위는 요구사항과 시안이다. 선택 후 P0 구현은 로컬 목 데이터 검토까지 진행하며, 실제 인증·저장·유료 생성·배포의 출시는 후속 연결 단계의 검증을 조건으로 한다.

관리자사용 현황과 요청·크레딧 관리기존 역할·접근 제어 유지. E0 별도 정책은 후속 확정

3. 사용자 흐름과 정보구조

목적 카드 선택 → 브리프 확인 → 장면 기획 → 이미지 제작 → 스토리보드 검토 → 영상 제작 → 다운로드

공통 메뉴: 내 프로젝트 / 자산 보관함. 프로젝트 진입 후 기획 → 이미지 → 스토리보드 → 영상의 단계 표시. 설정·도움말·계정은 하단, 관리자 메뉴는 기존 권한 조건을 유지한다.

프로젝트 시작 모달을 간결하게 유지하고 목적 카드 선택은 기본 프롬프트와 안내 문구에 반영한다.

6. 데이터·기술 경계

현재 AspectRatio는 16:9와 9:16이다. 모델별 지원 해상도는 별도이며, 화면 방향 선택만으로 4K·초광폭 출력이 보장되지 않는다. 기존 ProjectStep·프로젝트 저장 및 역할 체계를 우선 재사용한다.

초기 템플릿은 프런트 정적 구성으로 관리하고, 선택한 메시지는 기존 기획 입력으로 복사한다. 조직 공용 데이터 추가 없이 P0를 구성한다.

자산의 로고·제품 형상은 레퍼런스로 제공해도 생성 모델이 항상 보존하지는 않는다. 정확한 문구·로고 보장이 필요하면 후속 오버레이 합성 기능으로 분리한다. CMS 제공 여부와 E0 연동 가능성은 서로 다른 사실이다.

9. 검증·성과 지표

  • 목 검토: 신규 프로젝트, 기존 프로젝트 열기, 빈 목록, 저장 실패, 생성 대기/실패/성공 샘플, 모바일 메뉴, 키보드 탐색을 모두 확인한다.
  • 선택안 구현 후 TypeScript·Vite 빌드 통과. 브랜드 노출 검색은 화면·출력물 대상이며 Git 이력과 과거 문서는 보존한다.
  • 후속 실연결 후: 사용자별 데이터 격리, 저장 후 재열기, 생성 실패 시 크레딧 처리, 다운로드 파일과 인쇄를 확인한다.
  • 사용성 목표(제안): 내부 검토자 5명 중 4명 이상이 도움 없이 프로젝트 시작. 첫 기획 진입 시간 2분 이내. 실측치가 아니다.
  • 출시 후 측정: 프로젝트 시작→첫 기획 완료율, 생성 성공률, 다운로드 도달률. 시안에서는 가상 지표를 실제 사용량처럼 표시하지 않는다.

10. 미확정 사항·비목표

외부 고객 공개 여부, 초기 크레딧·요금, 운영자·문의처, 확정 로고, 공용 자산/승인 권한, 배포 도메인은 결정 필요. 결제·팀 협업·AI 가상피팅·장치 제어·송출 스케줄·자동 다중비율 변환은 P0에 포함하지 않는다.
