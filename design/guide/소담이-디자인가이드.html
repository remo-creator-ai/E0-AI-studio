소담이 디자인 시스템

소담스퀘어 마스코트 ‘소담이’의 캐릭터 컬러를 기반으로 한 v2 디자인 시스템입니다. 네이비·골드·레드 3색의 따뜻하고 친근한 아이덴티티로 소상공인의 꿈을 함께합니다.

소담이 소개

캐릭터 가이드 기반

소담이는?

소담스퀘어의 이름을 딴 ‘소담이’는 소상공인의 다양한 꿈을 함께 이뤄나가는 친구입니다. 활발하고 행복한 표정으로 보는 모두를 기분 좋게 만들어 줍니다. “소담이가 소상공인들의 꿈을 같이 이뤄나갑니다.”

머리 위 네모 뿔 🟨

소담이 머리 위의 네모 뿔(골드)은 소담이의 기분을 나타내는 상징입니다. 조끼에는 이름표 ‘소담이’와 소담스퀘어 배지를 달고 있습니다. UI에서는 이 골드를 포인트/하이라이트로 활용합니다.

앱 적용 (styles.css 토큰)

v1 바이올렛 → v2 소담이 교체
/* :root — 소담이 v2 (네이비·골드·레드) */
--primary:        #293463;  /* 네이비 (옷 색) — 메인 */
--primary-strong: #1E2650;
--primary-tint:   #E7E9F1;
--accent:         #F9CB5D;  /* 골드 (머리장식·단추) */
--point:          #FA3E3D;  /* 레드 (머리 기둥·강조) */
--bg:             #F7F4F1;  /* 웜 오프화이트 */
--surface:        #FFFFFF;
--cream:          #F3DDD1;  /* 크림 서브 서피스 */
--text:           #262626;
--text-2:         #5B554F;
--border:         #E7E1DC;
적용 방식: v1과 동일하게 styles.css의 :root 토큰만 교체하면 bg-primary·text-primary 계열이 자동 반영됩니다. 다만 v1은 단색 바이올렛이라 primary 하나로 충분했지만, 소담이는 3색 시스템이라 골드(accent)·레드(point)를 보조 CTA·뱃지·강조에 의도적으로 배치해야 캐릭터 아이덴티티가 살아납니다.
